## 1. ระบบรายงานคืออะไร

### 💡 อธิบายง่ายๆ
ระบบรายงานคือ **"การสรุปข้อมูลเป็นเอกสาร"** - เอาข้อมูลทั้งหมดมาจัดเรียง คำนวณ แล้วแสดงผลให้อ่านง่าย

### 🎯 ทำไมต้องมีรายงาน?
- **สรุปข้อมูลมากๆ** ให้เห็นภาพรวม
- **วิเคราะห์ผลงาน** รู้ว่าทำได้ดีหรือไม่
- **ตัดสินใจ** จากข้อมูลที่ถูกต้อง
- **ส่งต่อ** ให้ผู้บริหาร/ธนาคารแห่งประเทศไทย

## 3. คำศัพท์ที่ต้องรู้

### 📖 คำศัพท์สำคัญ

| คำศัพท์ | ความหมาย | ตัวอย่าง |
|--------|---------|---------|
| **Portfolio** | สินเชื่อทั้งหมดที่ยังมีความเสี่ยง | DISBURSED, ACTIVE, NPL, DEFAULTED |
| **DPD** | Days Past Due (จำนวนวันค้างชำระ) | DPD 45 = ค้าง 45 วัน |
| **NPL** | Non-Performing Loan (สินเชื่อเสีย) | ค้าง 30+ วัน หรือสถานะ NPL |
| **Collection Rate** | อัตราการเก็บเงิน | ได้รับ 90 บาท จากที่ต้องได้ 100 บาท = 90% |
| **NPL Ratio** | สัดส่วนหนี้เสีย | NPL 10 ราย / Portfolio 100 ราย = 10% |
| **Outstanding** | ยอดคงเหลือที่ต้องชำระ | เงินต้นที่ลูกค้าค้าง |
| **Disbursement** | การโอนเงินกู้ | เงินออกจากระบบให้ลูกค้า |

## 5. ปัญหาที่พบบ่อย

### ❌ "รายงานไม่มีข้อมูล"

**สาเหตุ:**
- ยังไม่มีสินเชื่อในช่วงเวลาที่เลือก
- Filter คัดกรองมากเกินไป

**ทำยังไง:**
```
✓ ขยายช่วงเวลา (เลือกเดือนที่แล้ว)
✓ ลดจำนวน Filter (เลือก "ทั้งหมด")
✓ ตรวจสอบว่ามีข้อมูลจริงไหม
```

---

### ❌ "ตัวเลขไม่ตรงกับที่คิด"

**สาเหตุ:**
- รายงานอัปเดตตามเวลา (ไม่ real-time)
- มีการเปลี่ยนแปลงหลังดึงข้อมูล

**ทำยังไง:**
```
✓ กด Refresh/โหลดใหม่
✓ ตรวจสอบช่วงเวลาที่เลือก
✓ ดูจากหน้าละเอียดแทน
```

---

### ❌ "NPL Ratio สูงกว่าที่คิด"

**สาเหตุ:**
- NPL = 30+ DPD ไม่ใช่ 90+ DPD
- รวมสถานะ NPL และ DEFAULTED

**ทำยังไง:**

## สรุปง่ายๆ

### 🎯 จำไว้ 6 ข้อ

1. **มีรายงาน 5 ประเภท**: Branch, Officer, NPL, Loan, Payment
2. **Portfolio** = DISBURSED + ACTIVE + NPL + DEFAULTED
3. **NPL** = ค้าง 30+ วัน หรือสถานะ NPL/DEFAULTED
4. **DPD Buckets**: Current → 1-7 → 8-29 → 30-89 → 90+
5. **Collection Rate** = เก็บได้ / ควรได้ × 100
6. **Export ได้** เป็น Excel/CSV ส่งต่อได้
