# 🔐 Generate Production Secrets

สำหรับ production ต้องสร้าง secrets ใหม่ทั้งหมด **อย่าใช้ค่าจาก .env เดิม!**

## 🎲 วิธีสร้าง Secrets

### Option 1: ใช้ Node.js (แนะนำ)

```bash
# สร้าง JWT_SECRET (64 characters)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# สร้าง JWT_REFRESH_SECRET (64 characters)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# สร้าง SESSION_SECRET (64 characters)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

# สร้าง ENCRYPTION_KEY (32 characters)
node -e "console.log(require('crypto').randomBytes(16).toString('hex'))"
```

### Option 2: ใช้ OpenSSL

```bash
# สร้าง JWT_SECRET (64 characters)
openssl rand -hex 32

# สร้าง JWT_REFRESH_SECRET (64 characters)
openssl rand -hex 32

# สร้าง SESSION_SECRET (64 characters)
openssl rand -hex 32

# สร้าง ENCRYPTION_KEY (32 characters)
openssl rand -hex 16
```

### Option 3: ใช้ Online Generator

ไปที่: https://generate-secret.vercel.app/32

หรือ: https://www.random.org/strings/

## 🚀 Quick Setup Script

สร้างไฟล์ `generate-secrets.sh`:

```bash
#!/bin/bash

echo "🔐 Generating Production Secrets"
echo "================================="
echo ""

echo "Copy these values to Railway Dashboard:"
echo ""

echo "JWT_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
echo "JWT_REFRESH_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
echo "SESSION_SECRET=$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
echo "ENCRYPTION_KEY=$(node -e "console.log(require('crypto').randomBytes(16).toString('hex'))")"

echo ""
echo "⚠️  Save these values securely!"
echo "⚠️  Never commit these to Git!"
```

Run:
```bash
chmod +x generate-secrets.sh
./generate-secrets.sh
```

## ⚠️ Security Best Practices

1. **Never reuse secrets** - สร้างใหม่ทุกครั้งสำหรับ production
2. **Never commit secrets** - อย่า commit ลง Git
3. **Use different secrets** - ใช้คนละชุดกับ development
4. **Store securely** - เก็บใน password manager
5. **Rotate regularly** - เปลี่ยนทุก 3-6 เดือน
6. **Limit access** - ให้เฉพาะคนที่จำเป็นเท่านั้น

- [ ] ลบ secrets จาก terminal history
- [ ] ไม่ commit secrets ลง Git
- [ ] แชร์ secrets ผ่านช่องทางปลอดภัย (ถ้าจำเป็น)

## 🔄 Rotating Secrets

เมื่อต้องการเปลี่ยน secrets:

1. สร้าง secrets ใหม่
2. อัพเดทใน Railway Dashboard
3. Railway จะ restart service อัตโนมัติ
4. ทดสอบว่าระบบทำงานปกติ
5. ลบ secrets เก่าออกจากทุกที่

## 🆘 If Secrets Leaked

1. **Immediate**: เปลี่ยน secrets ทันที
2. **Revoke**: ยกเลิก tokens ทั้งหมด
3. **Audit**: ตรวจสอบ logs หา unauthorized access
4. **Notify**: แจ้งทีมและผู้ใช้ (ถ้าจำเป็น)
5. **Review**: ทบทวน security practices
