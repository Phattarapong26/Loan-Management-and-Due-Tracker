## 1. ตั้งค่าระบบคืออะไร

### 💡 อธิบายง่ายๆ
ตั้งค่าระบบคือ **"การปรับแต่งระบบให้ทำงานตามต้องการ"** - เหมือนตั้งค่ามือถือ แต่เป็นการตั้งค่าธุรกิจ

### 🎯 ทำไมต้องมี?
- **ปรับอัตราดอกเบี้ย** ตามนโยบายธนาคารแห่งประเทศไทย
- **กำหนดขีดจำกัด** ว่าใครอนุมัติสินเชื่อได้เท่าไหร่
- **เปลี่ยนค่าต่างๆ** โดยไม่ต้องแก้โค้ด
- **แจ้งเตือนอัตโนมัติ** เมื่อมีการเปลี่ยนแปลง

### 👤 ใครใช้ได้?
- **Admin** เท่านั้น - คนตั้งค่าระบบ
- **Manager** ดูได้บางส่วน - ดู MLR/MRR ได้
- **Officer** ดูได้อย่างเดียว - ดู MLR/MRR ได้

## 3. MLR/MRR คืออะไร

### 📖 นิยาม

| คำศัพท์ | ความหมาย | ใช้กับ |
|--------|---------|--------|
| **MLR** | Minimum Loan Rate | สินเชื่อรายใหญ่ (Corporate) |
| **MRR** | Minimum Retail Rate | สินเชื่อรายย่อย (Retail) |

### 💰 การคำนวณดอกเบี้ยลูกค้า
```
ดอกเบี้ยลูกค้า = MLR/MRR + Spread

ตัวอย่าง:
• MLR = 8.00%
• Spread = 2.00%
• ดอกเบี้ยลูกค้า = 8.00% + 2.00% = 10.00%
```

## 6. ปัญหาที่พบบ่อย

### ❌ "เปลี่ยน MLR แล้ว แต่สินเชื่อเก่ายังใช้อัตราเดิม"

**สาเหตุ:**
- MLR/MRR เปลี่ยนมีผลกับสินเชื่อใหม่เท่านั้น
- สินเชื่อเดิมใช้อัตราตอนสร้างสัญญา

**ทำยังไง:**
```
✓ ปกติ: สินเชื่อเดิมควรใช้อัตราเดิม (สัญญาแล้ว)
✓ ถ้าต้องการเปลี่ยน: ต้องทำสัญญาใหม่/แก้ไขสัญญา
✓ ติดต่อลูกค้าหารือเรื่อง Refinance
```

---

### ❌ "Officer บ่นว่าอนุมัติสินเชื่อไม่ได้"

**สาเหตุ:**
- ยอดสินเชื่อเกินขีดจำกัดที่มีสิทธิ์
- ต้องส่งให้ Manager/HQ อนุมัติ

**ทำยังไง:**
```
✓ ตรวจสอบยอดสินเชื่อ vs ขีดจำกัด
✓ ถ้าเกิน → ส่งให้ Manager อนุมัติ
✓ หรือลดยอดสินเชื่อให้เหลือในขีดจำกัด
✓ หรือขอเพิ่มขีดจำกัด (ติดต่อ Admin)
```

---

### ❌ "Manager บ่นว่าต้องอนุมัติเยอะเกินไป"

**สาเหตุ:**
- ขีดจำกัด Officer ต่ำเกินไป
- สินเชื่อส่วนใหญ่เกิน 500,000

**ทำยังไง:**
```
✓ ปรับขีดจำกัด Officer ให้สูงขึ้น
✓ เช่น: จาก 500,000 → 1,000,000
✓ Admin ตั้งค่าใน Approval Limits
✓ มีผลทันทีกับสินเชื่อใหม่
```

---

### ❌ "พนักงานไม่เห็นการแจ้งเตือน MLR เปลี่ยน"

**สาเหตุ:**
- LINE ไม่ผูกบัญชี
- ไม่ได้เป็นเพื่อนกับ Official Account

**ทำยังไง:**
```
✓ ตรวจสอบว่าผูก LINE ID ในระบบแล้ว
✓ ตรวจสอบว่าเป็นเพื่อน OA แล้ว
✓ ทดสอบส่งข้อความจากระบบ
✓ ถ้ายังไม่ได้ → ลองผูกใหม่
```

---

### ❌ "ต้องการคืนค่าเริ่มต้น"

**สาเหตุ:**
- ตั้งค่าผิด
- ต้องการ Reset

**ทำยังไง:**
```
✓ ไม่มีปุ่ม Reset อัตโนมัติ
✓ Admin ต้องแก้ไขค่าเอง
✓ หรือลบ Config แล้วสร้างใหม่
✓ บันทึกค่าเก่าไว้ก่อนเปลี่ยน
```

## สรุปง่ายๆ

### 🎯 จำไว้ 6 ข้อ

1. **ตั้งค่าระบบ = ปรับแต่งให้ทำงานตามต้องการ** (เหมือนตั้งค่ามือถือ)
2. **MLR** = ดอกเบี้ยขั้นต่ำสินเชื่อ | **MRR** = ดอกเบี้ยขั้นต่ำลูกค้ารายย่อย
3. **อนุมัติ 3 ระดับ**: Officer (≤500K) → Manager (≤15M) → HQ (>15M)
4. **Admin เท่านั้น** ที่ตั้งค่าระบบได้
5. **เปลี่ยน MLR/MRR** → แจ้งเตือน LINE อัตโนมัติ
6. **ขีดจำกัดเปลี่ยน** → มีผลทันทีกับสินเชื่อใหม่

### 📏 ค่าปกติที่ใช้

| ค่า | ปกติ | หมายเหตุ |
|-----|------|----------|
| MLR | 7.50-8.50% | ตาม ธปท. |
| MRR | 7.00-7.75% | ตาม ธปท. |
| Officer Limit | 500,000 | ปรับได้ |
| Manager Limit | 15,000,000 | ปรับได้ |
| Grace Period | 7 วัน | ปรับได้ |

|-------|--------|

| ตั้งค่าอื่นๆ | Admin |
| LINE ไม่แจ้งเตือน | Admin |
| คืนค่าเริ่มต้น | Admin |
